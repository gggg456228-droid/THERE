# THERE Android 2.6.9

This project is based on the original THERE mobile source from the private handoff archive.

The in-app site viewer is intentionally absent. There is no WebView. The site opens only after the user presses "Открыть сайт", which launches the system browser.

The local Flask server runs in a foreground service so it can remain alive while the browser is in front. Core Python files are reused directly from `WINDOWS_X64/runtime/app`, so Android and Windows stay on the same THERE server code.

The GitHub workflow builds an installable ARM64 debug APK and publishes it to `dist/THERE_ANDROID_ARM64_2.6.9.apk`.

The public build uses the Android debug signing key generated by the CI runner. For stable upgrade-compatible production signing, configure a private keystore as GitHub Actions secrets instead of committing a signing key to this public repository.
